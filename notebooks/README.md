# Cuadernos de Google Colab

- `3D-ST-Colab-Plantilla.ipynb`: plantilla general para ejecutar TripoSR manualmente. Solicita una fotografía al comienzo.
- Al subir una fotografía desde la web de 3D-ST, la aplicación crea un cuaderno personalizado `.ipynb` con esa fotografía incorporada; ese archivo se descarga desde la pantalla de resultado y no vuelve a pedir la imagen.

Abre el `.ipynb` en Colab con Archivo → Subir cuaderno y ejecuta las celdas en orden.
